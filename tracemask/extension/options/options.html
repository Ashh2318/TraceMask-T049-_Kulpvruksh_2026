TraceMask for Chrome

A different you for every website. Works with the TraceMask app on this computer.

Pair this browser

  1. Start the TraceMask app on this computer (start.bat) and unlock it.
  2. In TraceMask, open Settings → Browser extension and click Generate pairing code.
  3. Type the 8-character code here. It works once and expires after 5 minutes.
Advanced: TraceMask address

Preferences

Keyboard shortcut to fill your alias: Alt+Shift+E

How to use it

1Click an email field

On any sign-up page, click the mask button that appears in the email box.

2Pick the purpose

One-time, regular, recoverable or bank/KYC. TraceMask recommends the right trust tier from the live risk score.

3Create & fill

A unique alias is created for that site only and filled into the form. If it ever arrives from anyone else, that is a leak.

Other ways: right-click an input → Fill TraceMask alias for this site, or click the TraceMask toolbar icon to see the site's risk, your alias and open leaks.

Privacy

  • The extension talks only to the TraceMask app on this computer (localhost). No cloud server, no analytics.
  • It sends the address of the page you act on, and only when you click. Page content, passwords and form data are never read or sent.
  • Access uses a per-browser key that is stored hashed in TraceMask. You can revoke it any time from either side.
